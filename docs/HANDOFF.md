## 4. 데이터 규칙 (중요)

- `foods.json`의 영양값은 모두 **100g당**이다. 액체는 100ml당.
  - 섭취량은 `per100 × 먹은 g ÷ 100`으로 계산한다.
  - 기본 섭취량은 `serving.g`, 화면에 보일 라벨은 `serving.label`("10장", "1공기" 등)을 쓴다.
- 값의 출처가 두 가지다.
  - `src.fiber` / `src.protein` = `"pdf"`: 가이드북 수치
  - `"est"`: 가이드북에 없어서 공개 영양 DB 기준으로 넣은 추정치. 가이드북은 식이섬유 표와 단백질 표가 따로 있어서 한 식품에 두 값이 다 있는 경우가 드물다. 필요하면 UI에 "추정" 표시를 한다.
- 가이드북 식이섬유 함량표 ②(콩·곡물·과일)는 1회 섭취 기준 값만 있어서 100g당 값으로 환산했다.
- 식품을 추가하거나 고칠 때는 `build_foods.py`의 `FOODS` 목록을 수정하고 `python3 data/build_foods.py`를 실행한다. JSON을 직접 고치지 않는다.
- `guide.json`의 `mealPatterns`는 끼니별 수치가 가이드북 그대로다. 그런데 **원문에 적힌 합계가 끼니별 합과 다르다.**
  - 집밥형 식이섬유: 적힌 값 33g, 실제 합 39.3g
  - 시간 없는 날 단백질: 적힌 값 91g, 실제 합 118g
  - 그래서 합계는 반드시 끼니별 값을 더해서 계산한다.

## 5. 핵심 공식

```
BMI = 체중 ÷ 키(m)²
갈래: BMI ≥25 → A | 23~25 → B | ≤23 → C | ≤23 + 골격근 표준 이하 → D
      (D는 BMI로 판별할 수 없어서 온보딩에서 "근육량 표준 이하?"를 선택 입력으로 받는다)
식이섬유 목표 = 여 25g / 남 30g
  주차별로 단계적으로 올린다: 1주 20→25, 2주 25→30, 3~4주 30 (guide.json weeks[].fiberTarget)
단백질 목표 = 체중 × 1.5g (3주차에 골격근이 줄었다면 ×1.7), 한 끼 = 하루 목표 ÷ 3
물 = 체중 × 30ml, 잠 7h 이상, 걸음 7,000 이상
4주 목표 체중: A −4~6 / B −3~4 / C −1~2 / D는 유지 (guide.json types[].goal4w)
```

## 6. 기능별 설계 메모

### 하루 섭취량
- 식품을 검색하거나 카테고리에서 고른 뒤 섭취량을 입력한다. 1회 단위나 g으로 입력할 수 있게 한다.
- 오늘 식이섬유·단백질 합계를 목표 대비 진행 바로 보여준다.
- 먹은 식품별 목록과 카테고리별 합계를 보여준다.
- 식단 패턴이나 조합 같은 **메뉴 프리셋**을 한 번에 추가하는 기능도 있으면 좋다. 백반집·도시락처럼 식품 단위로 쪼갤 수 없는 메뉴가 있기 때문이다.

### 28일 기록 (가이드북 18~19쪽 기록지 기준)
- 하루 기록: `{ date, weight, fiber, protein, water, sleep, exercise, steps, bannedCount, gratitude }`
  - 항목 정의는 `guide.json`의 `dailyLogFields`에 있다.
- fiber·protein은 그날 먹은 식품 기록에서 자동으로 합산한다.
- 시작일을 저장해 두고 DAY 1~28과 주차(1~4)를 계산한다. 주차에 맞는 미션과 금지 목록(`guide.json` `weeks`)을 보여준다.
- 따로 기록할 것:
  - 2주차 중간 점검: 체중, 허리둘레
  - 1일차/28일차 비교: 체중, 체지방량, 골격근량, 허리둘레, 컨디션, 군것질 생각 (`guide.json` `measurements`)

### 체중 그래프
- Recharts 라인 차트로 그린다. 일별 체중과 **7일 이동평균**을 같이 보여준다. 원문에 "하루 숫자가 아니라 7일 흐름을 보라"는 말이 있다.
- 갈래별 4주 목표 범위를 기준선이나 밴드로 표시한다.
- 2주차 정체기 안내를 붙인다: "체중계 대신 허리둘레를 보세요".

### 메뉴 추천 (규칙 기반)
- 오늘 남은 양을 계산한다: 식이섬유 목표 − 섭취량, 단백질 목표 − 섭취량.
- 남은 양을 가장 잘 채우는 후보를 추천한다. 후보는 `protein30`, `fiberCombos`, `snacks`, `breakfastSets`, 그리고 `foods` 중 고식이섬유·고단백 식품이다.
- 요일에 맞는 단백질 로테이션(`proteinRotation`)을 우선 추천한다.
- 끼니 시간대로 아침·점심·간식·저녁을 나눠 추천한다.
- 외식 모드에서는 장소별로 고를 것과 피할 것(`eatingOut`)을 보여준다.
- 금지 식품을 검색하면 대체 식품(`banned[].swap`)을 보여준다.
- 갈래 C는 밥 양을 1/2로 줄이고 간식 하나를 빼라는 안내를, 갈래 D는 양을 줄이지 말라는 안내를 보여준다.
