# 가이드북 분석 메모

원본: `guidebook.pdf` (21쪽), 텍스트 추출본: `guidebook-source.txt`

## 데이터 파일

- `data/foods.json` — 식품 87개. 100g(액체는 100ml)당 식이섬유·단백질 값과 1회 섭취량(g, 라벨).
  - `src`가 `pdf`면 가이드북 수치, `est`면 가이드북에 없어서 공개 영양 DB 기준으로 넣은 추정치.
  - 가이드북 식이섬유 함량표 ②(콩·곡물·과일)는 1회 섭취 기준 값만 있어서 100g당 값으로 환산했다.
  - 수정은 `data/build_foods.py`에서 하고 `python3 build_foods.py`로 다시 생성한다.
- `data/guide.json` — 목표 공식, 갈래 A~D, 주차별 미션, 하루 기록 항목, 금지·대체 식품,
  단백질 7일 로테이션, 하루 식단 3패턴, 식이섬유 30g 조합, 단백질 30g 조합, 아침 세트, 간식, 외식 가이드.

## 공식

- BMI = 체중 ÷ 키(m)² → ≥25 A, 23~25 B, ≤23 C (골격근 표준 이하이면 D)
- 식이섬유: 여 25g / 남 30g, 주차별 단계적으로 올림 (1주 20→25, 2주 25→30, 3~4주 30), 한 주에 최대 +5g
- 단백질: 체중 × 1.5g (3주차에 골격근이 줄었다면 × 1.7g), 한 끼 = 하루 목표 ÷ 3
- 물: 체중 × 30ml, 잠 7h+, 걸음 7,000+
- 최대심박 ≈ 220 − 나이, 존2 60~70%, 존5 90% 이상

## 원문에서 맞지 않는 부분

11쪽 식단 3패턴은 끼니별 수치를 더한 값과 적혀 있는 합계가 다르다.

| 패턴 | 적힌 합계 | 끼니별 합 |
|---|---|---|
| 집밥형 식이섬유 | 33g | 39.3g |
| 시간 없는 날 단백질 | 91g | 118g |

→ 앱에서는 끼니별 수치를 더해서 합계를 계산한다.
